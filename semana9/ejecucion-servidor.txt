Cuando ejecuto el comando node server.js, Node.js inicia el servidor web definido en el archivo.

En la terminal aparece el mensaje:

Servidor ejecutándose en puerto 3000

Cuando visito la ruta http://localhost:3000/estado, el servidor responde con un objeto JSON que indica que el servidor está funcionando correctamente y que el servicio corresponde a una API comunitaria.

Respuesta:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
