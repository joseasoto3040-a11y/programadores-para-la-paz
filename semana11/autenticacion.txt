El login es el proceso que permite identificar a un usuario antes de darle acceso a una aplicación. Gracias al inicio de sesión, solo las personas autorizadas pueden ingresar a ciertas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. Esto ayuda a mantener la seguridad del sistema. No se deben mostrar públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles.
